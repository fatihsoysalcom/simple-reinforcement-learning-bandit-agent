# Simple Reinforcement Learning Bandit Agent

This Python script demonstrates a simple self-improving AI agent using the Reinforcement Learning concept of a Multi-Armed Bandit problem. The agent learns through 'trial-and-error' (an epsilon-greedy strategy) to identify and exploit the most rewarding option among several choices. Over time, it adapts its strategy to maximize total rewards, illustrating how an agent can improve its performance based on experience.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
